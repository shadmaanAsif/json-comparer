# Archive

Historical material, kept for traceability only. Nothing here describes the current
application.

## `source/`

The pre-implementation analysis of the original single-HTML-file artifact that predated
this Next.js application (`docs/archive/source/README.md`, `FEATURES.md`, `SRS.md`,
`ARCHITECTURE.md`, `TECH_STACK.md`, `IMPLEMENTATION_PLAN.md`). It documents what that old
artifact did and proposed, including behavior the current app deliberately redesigned or
rejected — see `docs/reference/ARCHITECTURE.md` and `docs/reference/SRS.md` for what
actually shipped.

**Do not read this by default.** Consult it only when tracing the origin of a specific
historical decision (for example, writing or reviewing an ADR that references why the old
artifact's behavior was rejected). For understanding current behavior, requirements, or
architecture, use `docs/reference/` and `FUNCTIONALITY.md` instead.
